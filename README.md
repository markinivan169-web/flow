# Пять букетов

Демонстрационный сайт цветочной мастерской на Next.js App Router, TypeScript и Tailwind CSS. GSAP ScrollTrigger связывает первый экран и каталог, GSAP FLIP раскрывает фотографии из сетки, а Lenis сглаживает прокрутку на поддерживаемых устройствах.

## Локальный запуск

Требуется Node.js 20.9 или новее. Распакуйте архив и выполните команды в папке проекта.

```sh
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для проверки production-сборки используйте `npm run build` и `npm start`. Команда `npm run check` проверяет типы.

## Данные и медиа

- `assets/catalog-originals` содержит восемь исходных JPG размером 3200 × 4000. Они хранятся вне `public`.
- `public/media/catalog` содержит восемь WebP размером 1600 × 2000 на основе фотографий заказчика. `next/image` подбирает размеры для сетки, галереи и открытого просмотра. Увеличение в карточке запрашивает вариант большего размера.
- Видео главного экрана подготовлено из `начальный фон.mp4`. Десктопная и мобильная версии H.264 используют постеры из первого кадра.
- В `app/site.ts` собраны временные названия и визуальные описания букетов, порядок галереи, контакты, логотип и условия доставки. Для подключения логотипа поместите файл в `public/media` и заполните `studio.logo`, указав публичный путь и размеры.
- Форма заявки позволяет подготовить черновик в браузере, скопировать его или скачать. Настройка приёма заявок зависит от реальных контактов мастерской.
- Unbounded и Montserrat поставляются локально через Fontsource.
